## [Unreleased]

LibreOmi has not had a public release yet. Version is being reset to 0.1.0 for the
first public build (see `pubspec.yaml`).

### Added

- Negotiate a larger BLE MTU, prioritize the connection, and cache characteristics for
  faster, more stable device connections ([#46](https://github.com/johnpark-bin/LibreOmi/pull/46))
- Add runtime permission declarations and request flow ([#48](https://github.com/johnpark-bin/LibreOmi/pull/48))
- Prompt once to exclude the app from battery optimization, with manufacturer-specific
  guidance pages ([#53](https://github.com/johnpark-bin/LibreOmi/pull/53))
- Keep recording in the background via a foreground service, with wakelock and idle
  shutdown handling ([#54](https://github.com/johnpark-bin/LibreOmi/pull/54))
- Reconnect automatically to the device using armed autoConnect, exponential backoff,
  and GATT 133/257 retries ([#56](https://github.com/johnpark-bin/LibreOmi/pull/56))
- Retry conversation summarization automatically once network connectivity recovers
  ([#57](https://github.com/johnpark-bin/LibreOmi/pull/57))
- Add a model store screen with download progress, cancel, verification, and deletion
  ([#67](https://github.com/johnpark-bin/LibreOmi/pull/67))
- Add a Korean offline transcription model option ([#70](https://github.com/johnpark-bin/LibreOmi/pull/70))
- Transcribe SD-card recordings into summarized conversations (Deepgram pre-recorded
  and on-device offline) ([#73](https://github.com/johnpark-bin/LibreOmi/pull/73))

### Changed

- Rename the app and package to LibreOmi ([#42](https://github.com/johnpark-bin/LibreOmi/pull/42))
- Move the API key into secure storage, migrating it once and excluding it from Auto
  Backup ([#55](https://github.com/johnpark-bin/LibreOmi/pull/55))
- Move on-device streaming transcription decoding to a worker isolate and add
  timestamps, keeping the UI responsive ([#68](https://github.com/johnpark-bin/LibreOmi/pull/68))
- Split offline batch transcription on detected speech segments for better accuracy
  ([#69](https://github.com/johnpark-bin/LibreOmi/pull/69))
- Rework the SD-card page to use a dedicated controller and remove the placeholder
  screen ([#75](https://github.com/johnpark-bin/LibreOmi/pull/75))

### Fixed

- Clean up notification icons and channels, and remove a missing notification sound
  resource ([#44](https://github.com/johnpark-bin/LibreOmi/pull/44))
- Count Deepgram usage from final transcription results only, and make the model
  configurable ([#45](https://github.com/johnpark-bin/LibreOmi/pull/45))
- Switch reminder alarms to inexact scheduling and stabilize notification IDs
  ([#47](https://github.com/johnpark-bin/LibreOmi/pull/47))
